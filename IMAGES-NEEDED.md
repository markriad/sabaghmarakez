# Photographs needed

Every image slot on the site. Fill in the **Sending** column, put the files in
one folder named however you like, and send the folder with this document —
I'll place them, check each one renders, and return a build.

You don't need to match the sizes exactly. Every slot is a fixed shape and
crops from the centre, so nothing can break the layout. Matching them just
avoids an unexpected crop.

**Filename convention** — anything readable is fine, e.g. `ramla-hero.jpg`,
`shams-villa-1.jpg`, `shams-villa-2.jpg`. Numbered suffixes go in the carousel
in that order.

Nothing, if the filename says it. If a file could be ambiguous — which unit type,
which project — put it in a subfolder named after the project.

## One caution

Send the original files, not screenshots or exports from a PDF. Anything lifted
from a brochure page is already compressed once and will look soft when the site
re-encodes it. If the only copy you have is the brochure, tell me and I'll extract
at the best quality available rather than you screenshotting.
